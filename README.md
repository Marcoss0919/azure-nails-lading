# 💅 Landing Page - Salão de Manicure

Este projeto é uma **Landing Page** desenvolvida para um salão de manicure/nail design, criada com o objetivo de praticar e aplicar conhecimentos em **HTML, CSS e JavaScript puro**.

---

## 🚀 Objetivo
- Criar uma página simples e atrativa para divulgar serviços de manicure.  
- Exercitar conceitos de **estruturação HTML**, **estilização com CSS** e **interatividade com JavaScript**.  
- Reforçar boas práticas de desenvolvimento Front-End.

---

## 🛠️ Tecnologias utilizadas
- **HTML5** → Estrutura da página  
- **CSS3** → Estilização e layout responsivo  
- **JavaScript** → Interatividade e dinamismo  

---

## 🎨 Funcionalidades
- Layout responsivo para diferentes dispositivos.  
- Seções de apresentação dos serviços.  
- Botões interativos com JavaScript.  
- Design simples e moderno.
